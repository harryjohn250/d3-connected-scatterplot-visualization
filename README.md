# D3 Connected Scatterplot Visualization

An interactive data visualization built with D3.js that extends a connected scatterplot with advanced user interaction, dynamic dataset support, and bivariate color encoding.

## Overview

This project visualizes temporal data using a connected scatterplot. It supports multiple datasets and allows users to explore relationships between variables through interactive controls.

## Features

- Connected scatterplot with animated path drawing
- Pan and zoom functionality
- Tooltip displaying detailed data values
- Time range filtering using sliders
- Highlighting of selected time intervals
- Bivariate color encoding for change between time steps
- Interactive legend for color interpretation
- Dynamic dataset switching
- Dropdown controls for:
  - X-axis selection
  - Y-axis selection
  - Hue (color dimension)
  - Lightness (secondary color dimension)
- Fully generalized to work with different CSV datasets

## Technologies Used

- D3.js (v7)
- HTML5
- CSS3
- JavaScript (ES6)
